# 📝 Suggested Extensions App  
A lightweight web application for managing and filtering suggested browser extensions. Built with React, TailwindCSS, and Flowbite for a responsive and modern UI.  

### 📌 Project Description  
This application allows users to:  

- View a list of suggested extensions.  
- Toggle extensions between **Active** and **Inactive** states.  
- Filter the list by **All**, **Active**, or **Inactive**.  
- Easily remove an extension from the list.  
- Enjoy a clean dark/light theme with persistence using local storage.  

### 🚀 Features  
✔️ Dark/Light theme with auto-persistence in local storage  
✔️ Responsive design built with TailwindCSS + Flowbite  
✔️ Filter extensions dynamically (All / Active / Inactive)  
✔️ Toggle extension state with Flowbite’s `ToggleSwitch`  
✔️ Reusable extension card component with name, description, and logo  
✔️ Simple and intuitive UI with minimal setup  

### 🛠 Tech Stack  
- React 19  
- TailwindCSS  
- Flowbite + Flowbite-React (UI components)  
- TypeScript (interfaces and type safety)  
- Local Storage API (theme persistence)  

### ⚡ Installation & Usage  
1. git clone https://github.com/your-username/suggested-extensions-app.git
2. cd suggested-extensions-app
3. npm install
4. npm run dev
5. Open `http://localhost:5173` in your browser
